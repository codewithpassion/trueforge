Adds `/api/v1/computer-desktops/{computer_id}` routes so anyone who may use a desktop agent can watch its computer's desktop, take control, send input, share the clipboard, and hand control back or cancel a pending takeover. Browser writes must come from the server's own origin; another person's control answers `423` with code `human_in_control`. Taking control and handing it back are audited as `computer.desktop.take_control` / `computer.desktop.hand_back` with the acting user. Hand-back and cancel answer `200` with `{ data: { status, takeover } }`: the desktop status after the request, and for a named session whether its takeover was `resumed`, `already_answered`, `not_pending` or `resume_failed`, with a message. Cancel is refused with `423` `human_in_control` while another person controls the desktop. A desktop tool refused because a person is in control tells the model to call `request_human_takeover` if it has that tool, else to stop and tell the user.
